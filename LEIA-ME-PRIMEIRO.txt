JUDICIAL PIPELINE - INSTALACAO NO WINDOWS

1. Instale e abra o Docker Desktop:
   https://www.docker.com/products/docker-desktop/

2. Extraia TODO o conteudo deste ZIP para uma pasta normal.
   Nao execute os arquivos diretamente de dentro do ZIP.

3. Clique duas vezes em INICIAR.bat.

4. Na primeira vez, o Bloco de Notas abrira o arquivo .env.
   Troque todos os valores de exemplo pelas senhas, usuario e chave DataJud.
   A senha de acesso ao sistema precisa ter pelo menos 12 caracteres.

5. Salve o arquivo .env e clique novamente em INICIAR.bat.

6. Ao terminar, o sistema abrira em http://localhost:8080.

ATALHOS
- INICIAR.bat: inicia e abre o sistema.
- PARAR.bat: para o sistema sem apagar os dados.
- VER-STATUS.bat: mostra o estado e os erros recentes.

IMPORTANTE
- O Docker Desktop precisa ficar aberto durante o uso.
- Nunca envie o arquivo .env para outras pessoas: ele contem credenciais.
- Este pacote local funciona apenas no computador em que foi instalado.
