JUDICIAL PIPELINE - LEIA-ME PRIMEIRO

PRIMEIRA INSTALACAO

1. Clique duas vezes em Judicial-Pipeline-Instalador.exe.
2. Autorize a instalacao quando o Windows perguntar.
3. Aguarde enquanto os componentes necessarios sao preparados. O reparo
   oficial do Windows ja acompanha o instalador e e validado automaticamente.
4. Se o instalador solicitar, reinicie o computador.
5. Clique no atalho Judicial Pipeline na area de trabalho.

USO NORMAL

- Clique no atalho Judicial Pipeline.
- Aguarde a pequena tela de preparacao desaparecer.
- O painel abrira automaticamente no navegador.
- Nao existe usuario, senha ou configuracao para preencher.

AO TERMINAR O USO

- Fechar o navegador nao encerra o mecanismo local.
- Clique duas vezes no atalho Encerrar Judicial Pipeline para liberar a memoria.
- Os imoveis, as observacoes e o historico serao preservados.
- Enquanto estiver encerrado, as buscas automaticas ficam pausadas.
- Para usar novamente, clique no atalho Judicial Pipeline.

AJUDA

Se o painel nao abrir, reinicie o computador e tente novamente. Se continuar,
envie ao responsavel tecnico:

- instalacao.log e preparacao-docker.log de
  C:\ProgramData\JudicialPipeline;
- preparacao-windows.log, reparo-wsl-msi.log, inicializacao.log,
  encerramento.log e inicio.log de
  %LOCALAPPDATA%\JudicialPipeline.

IMPORTANTE

- Os dados ficam armazenados neste computador.
- Nao apague a pasta C:\ProgramData\JudicialPipeline.
- Nao remova volumes ou dados pelo Docker Desktop.
- O programa precisa de internet para consultar novas oportunidades.
