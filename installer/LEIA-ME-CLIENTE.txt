JUDICIAL PIPELINE - GUIA PARA O CLIENTE

PRIMEIRA INSTALACAO

1. Baixe o arquivo Judicial-Pipeline-Instalador.exe.
2. Clique duas vezes no arquivo.
3. Quando o Windows perguntar, permita que o instalador faça alterações.
4. Aguarde. A primeira instalação prepara os componentes necessários e pode
   demorar. O reparo oficial do Windows já acompanha o instalador e é validado
   automaticamente, sem exigir download do GitHub.
5. Se aparecer a orientação para reiniciar, reinicie o computador.
6. Depois da reinicialização, clique no atalho Judicial Pipeline que estará na
   área de trabalho.

USO NORMAL

- Clique duas vezes no atalho Judicial Pipeline.
- Aguarde o navegador abrir.
- Não é necessário informar usuário ou senha.
- O endereço local é http://localhost:8080.
- Na primeira abertura, leia a apresentação e clique em "Entrar no painel".
- Para rever depois, use o botão "Como funciona" no topo do painel.
- O painel principal mostra somente os imóveis ainda ativos.
- Use "Arquivados / inativos" para consultar leilões cujo prazo terminou.
- A busca consulta Sublime, Mega, SPY, Portal Zuk, GL Leilões, PublicJud,
  DJEN/CNJ, TRT-15 e TRT-2 automaticamente.

AO TERMINAR O USO

- Fechar apenas o navegador não encerra o mecanismo local.
- Se quiser liberar a memória usada pelo Docker, clique com o botão direito no
  ícone do Docker perto do relógio do Windows e escolha "Quit Docker Desktop".
- No próximo uso, clique normalmente no atalho Judicial Pipeline; ele iniciará
  o mecanismo outra vez.

SE O WINDOWS MOSTRAR UMA PROTECAO

O instalador é personalizado e ainda não possui certificado comercial de
assinatura. Caso o Windows SmartScreen mostre um aviso, confira se o nome do
arquivo é Judicial-Pipeline-Instalador.exe e use "Mais informações" e
"Executar assim mesmo". Não faça isso com outros arquivos desconhecidos.

SE O SISTEMA NAO ABRIR

1. Reinicie o computador e clique novamente no atalho Judicial Pipeline.
2. Se continuar, envie ao responsável técnico:
   - instalacao.log e preparacao-docker.log da pasta
     C:\ProgramData\JudicialPipeline;
   - preparacao-windows.log, reparo-wsl-msi.log, inicializacao.log e inicio.log da pasta
     %LOCALAPPDATA%\JudicialPipeline.
3. O cliente não precisa editar configurações nem executar comandos.

DADOS E ATUALIZACOES

- Os dados ficam neste computador.
- Não apague a pasta C:\ProgramData\JudicialPipeline.
- Não use a opção de remover volumes/dados dentro do Docker.
- Mantenha uma cópia de segurança conforme a orientação do responsável técnico.
